# frontend

The NeoVNDB site (Next.js). It needs the services behind the edge, so start
the whole stack with `start.ps1` from the repository root and open
<http://127.0.0.1:17030>; see the [repository README](../README.md).

Before handing off a change: `pnpm typecheck`, `pnpm typecheck:tests`,
`pnpm lint`, `pnpm format:check`, `pnpm test`, `pnpm build`.
