# NeoVNDB 功能

> 最后更新：2026-11-13
> 现在能做什么，按功能分。只写做完并实测过的；没做的在 `计划.md`。实现细节在两份代码结构文档里。

---

## 一、镜像与导入

- 下载 vndb 的 dump，SHA256 校验，流式解 zstd + tar；42 张表按原样导入（`v17` 这类 id 改写成数字）。
- 派生 dump 不导出的东西：标签与特征的分数、剧透等级与继承展开，标签树与特征树的闭包，搜索索引，作品的发售日 / 语言 / 平台 / 开发商，全年龄列表，相似作品。
- 代次 `vndb` / `vndb_prev` / `vndb_next`：事务内原子换代，可回滚，回滚后可再前滚而不必重新导入。
- 上线前熔断：某表行数缩水超过阈值、少了表、派生表为空就拒绝上线；`-force` 可强过。
- `update` 一条命令兼管定时与手动：上游没有新的什么都不做，上游比线上旧则拒绝倒退。
- 定时更新在 `serve` 进程里跑（默认启动 10 分钟后第一次、之后每 24 小时）；连不上上游或下载失败时 1 小时后重试。
- 导入、上线、回滚共用一把 Postgres 咨询锁，定时与手动不会同时跑。
- 上线后只留最新 N 份归档（默认 2），本次导入用的那份永不删。
- 一次完整导入约 3 分半（下载另计，约 190 MB）。

## 二、读 API（`/vndbserve`）

| 路由 | 能做什么 |
|---|---|
| `GET /{type}` | 七种类型共用：`fields` 选字段（可嵌套到关联类型）、筛选、`f=` 条件表达式、排序、分页、搜索 |
| `GET /vn/{id}/relations` | 关系图：从一部作品往外走 N 步，点带深度、封面、开发状态、评分；回报步数上限与"再深也画不出新东西"的那一步 |
| `GET /facets/{type}/{filter}` | 分面计数：某个筛选的每个取值选上后剩多少条，按其余筛选算 |
| `GET /stats` | 整库统计，统计页用；每个代次在后台数一次（约 6 秒），之后直接给 |
| `GET /stats/vn` | 一组作品的共同点：开发商、发行商、各职位的人员、各分类的标签 |
| `GET /recommend/vn` | 按标签相似度加权的推荐，每部带"因为哪几部" |
| `GET /meta/openapi` | 由真实的字段表、筛选表、排序表生成的 OpenAPI 3.1 |
| `GET /meta/fields/{type}`、`/meta/extlinks`、`/meta/generation`、`/meta/viewer`、`/health` | 自省、外链站点清单、线上代次、这个读者被怎么回答 |

**查询**

- **条件表达式 `f=`**：`,` 或、`+` 与、`!` 非、括号分组，值含特殊字符时用双引号；与扁平参数是"且"。
- **关联嵌套**：`release=(lang=en+freeware=true)` 要求同一个发行同时满足；括号里是关联类型自己的筛选，所以给某类型加一个筛选，所有嵌套它的地方立刻能用。也能按名字找关联：`producer=(search=nitroplus)`、`tag=(search=school+category=cont)`。
- **标签与特征带阈值**：`tag=g749:2.0:1`（最低分、剧透上限），`trait=i568:1`（剧透上限）。
- **常用的专门筛选**：实测时长、关系类型、某人在这部作品里的职位（`credit=s224:scenario`）、分辨率、动画程度、生日、有无立绘、是否变体、封面的内容等级、外链站点、DRM。
- **搜索**：按词拆分、顺序无关，引号内按原序；最多 8 个词。`sort=searchrank` 按匹配质量排（完全相等 > 前缀 > 所有词在同一个名字里，再看相似度与人气）。标签与特征也能用日文译名搜到（`search=学園` → School），管理页改了译名立即生效；`/q` 同样。
- **描述检索**：`description=`（发行是 `notes=`）——每个词都要出现在简介里，规则与名字搜索相同（大小写、全半角折叠，子串匹配，中日文都能搜），BBCode 标记不算。全年龄模式下同样只给看得见的。
- **出错**：不认识的筛选、不合法的值、只能相等的筛选用了比较符，都回 400 并说明哪里不对。

**性能与缓存**：进程内 LRU 响应缓存（可换 Redis），按代次做键；常规查询几毫秒到几十毫秒，深翻页不退化。客户端中途离开回 499，超时回 504。

## 三、全年龄模式

- 未登录的读者只看到全年龄内容；管理页设为 Everyone 后已登录的也一样。改了即生效，不用重启。
- 挡住的：18+ 或含色情场景的发行；没有全年龄版的作品（有就只显示那一版；体验版不算）；没分级但带性内容标签的作品；只在被挡作品或发行里出场的角色；性内容类标签与带性标记的特征（连同下级）；性或暴力投票超过最低档、或没人投过的图片。
- 被挡的不发给浏览器：列表总数、搜索、筛选计数、统计、关系图、推荐都只算看得见的。保留下来的作品，发售日、语言、平台、开发商只按看得见的发行算；经被挡的东西去筛选问不出结果；指向被挡条目的边（配音、截图的发行、角色在成人版里的出场、`instance_of`）也不给。
- 直接打开被挡条目的地址显示"全年龄模式下不显示"（访客多一个登录按钮），不是 404；收藏夹与评分页里被挡的条目不出现，注明有几条。
- 每次导入自带全年龄列表；更早的一代可在管理页（或 `neovndb db withheld`）用已有数据重建，约 3 秒，不用重启。
- 图片服务本身不挡（知道地址仍能直接打开），按决定不处理。

## 四、图片镜像（`/imgserve`）

- 回源 t.vndb.org，只存原件，逐字节，不做缩放；缩略图用 vndb 自己的（封面 `cv.t`，只有宽于 256px 的封面才有；截图 `st`）。
- 盘上有的由边缘直接发，不进这个进程。
- 盘上没有的：默认 302 到 vndb（`no-store`）并在后台取回落盘；可在管理页切换为等服务器回源。上游 404 的图记一小时，不反复去问。
- 要的缩略图上游没有时给原图，不落假文件。
- 并发取同一张图只回源一次；回源并发有上限。
- 预取：按库里的 `images` 表找盘上没有的图，新的先取，每轮张数与间隔可设；`neovndb crawl` 手动跑。

## 五、用户服务（`/userserve`）

| 能力 | 说明 |
|---|---|
| 账号 | 注册、登录、登出、全端登出、改密码、注销（再输一次密码；收藏、评分、会话随之删除）。用户名只收 ASCII 字母数字与 `-` `_`，密码 8–72 字节，只有 bcrypt |
| 限流 | 登录与注册按来源地址、按用户名各自计数，超出回 429 与 `Retry-After`；改密码、注销时的再验密码也计入。次数与窗口可设 |
| 收藏夹 | 增删改；条目单条与批量加 / 删 / 移（保留收藏时间）；按收藏时间或我的评分排序；某条目在哪些列表里 |
| 评分 | 1–5 分，清除是删除不是 0 分；批量设分与清除 |
| 偏好 | 账号里存一份偏好（原文开关、内容等级、剧透、关系图开关），换设备接过来 |
| 保存的搜索 | 命名存进账号，同类型内名字唯一，每人条数有上限 |
| 给边缘用 | `/auth/verify`（谁、是否管理员）、`/auth/admin`、`/auth/viewer`（会员还是访客） |
| 备份 | 最新一份超过一周就 `pg_dump` 一份，留最新 8 份；`users backup` 立即备份 |

## 六、译文

- vndb 的标签与特征只有英文；本项目自备日文译名与译文，接在"原文"开关上。
- 放在生成 schema 之外（`trans`），按文本内容做键，换 dump 不必重解析；英文改了的就不命中、回落英文。
- 标签与特征的名字与描述全部有译文（以 2026-11 的代次为准）。
- 语料在仓库里（`internal/trans/init.json`），`trans seed` 载入；写入前校验 BBCode 与裸 id 原样保留，一条不过整份拒绝。改了立即生效（版本号进缓存键）。
- 管理页可逐条改，`trans export` 或管理页的 Export 写回语料文件。

## 七、边缘（:17030）

- 唯一对外地址；四个服务都只听回环。
- `/vndbserve`、`/imgserve`、`/userserve` 各有一份路由白名单，之外直接 403。
- `/admin` 路由先问用户服务是不是管理员；带会话 cookie 的读 API 请求先问是会员还是访客，交给读 API 一个 `X-Viewer`。
- 盘上已有的图片直接发。

## 八、前端（:17034，经边缘访问）

**浏览**

- 首页：按月看发行。
- 七种类型的列表页：筛选条（每个选项带"选上后剩多少"）、排序（点当前排序翻转方向）、搜索（搜索框右侧的按钮切换为搜简介；条件构建器里也有 Description / Notes 条件）、翻页（可跳到任意页），状态全在地址里。
- 条件构建器：条件读起来像一句话，芯片式编辑，组、取反、"有一个……满足"的嵌套块；多选；点连接词切换且 / 或并自动加括号；整理（拍平、合并、去重）；实时命中数；可切到 `f=` 文本互改。
- 详情页：作品（信息、标签、角色网格、发行按语言分组、人员按版次分组、截图、关联、相似）、角色、发行、制作方、人员、标签、特征。段落导航吸顶并点亮正在读的段。
- 关系图：可拖可缩，分层走线；步数只列到有用的那一步；定位、适配、找路径、六个视图开关、关系图例兼筛选、总览图。
- 全局搜索 `/q`：七类一次问完；完整 id 或只有一条结果时直接跳转；制作方、人员、角色段给出相关作品的链接。
- 目录页（制作方、人员、标签、特征）的"Refine in …"把当前标签页带到列表页继续加条件。
- 统计页 `/stats`：七类总数与按年月的新建数，作品、发行、制作方、角色（按性别分开）、人员、标签与特征的分布和排行；每张图可切表格。
- API 说明页 `/api`。

**读者自己的**（登录后）

- 收藏夹 `/u`：切换列表、搜索、排序（收藏时间、我的评分或 vndb 字段）、跨页勾选后批量删除 / 移动；vndb 已删的条目画成占位卡，可移除。
- 从任何结果列表"Select → Save to…"存进列表，也可当场新建。
- 我的评分 `/u/ratings`：按类型列出，批量设分或清除。
- 仪表盘 `/u/dashboard`：选来源、时间与粒度；作品数、评分、加入时间分布（日粒度为热力图）、发行年份、评分分布与和 vndb 的分歧、开发商 / 发行商 / 人员 / 标签 / 语言 / 长度，按评分加权的推荐；点任一柱整页收窄；列表很长、超过一次能读的条数时注明有多少没算进来。
- 保存的搜索与本机最近 8 次搜索；偏好跟账号走。

**显示设置**（顶栏"显示内容"菜单，任何页面可改）

- 原文 / 译文、性与暴力内容等级、剧透等级；存在 cookie 里，服务端直接按它渲染，不会在水合时整页改写。

**体验**

- 换页用 View Transition，顶栏不动；超过 120ms 时出进度条、结果区变暗；跳转时取消旧页没加载完的图片。
- 键盘：`/` 搜索、`←` `→` 翻页、`j` `k` 跳段、`?` 看全部快捷键；菜单与分段选择可用方向键；灯箱接过焦点。
- 响应式：320–1920 宽无横向溢出；触屏下可点元素高度 ≥24px；慢网下各页 CLS ≈ 0。
- 数字固定写成 1,234，不随浏览器语言变。

## 九、管理页 `/admin`（只给管理员）

- **Mirror**：线上与上一代的代次与时间、库大小、译文条数；更新任务（上次结果、下次时间、输出末尾，运行中自动刷新）与 Check now；保留的归档；回滚（二次确认）；图片预取的覆盖率与 Crawl now；用户库备份与 Back up now；All ages 卡片（列表状态、Build the list、Guests / Everyone 开关）。
- **运行中可改的设置**：更新间隔与重试间隔、留几份归档、熔断阈值；盘上没有的图怎么给、预取间隔 / 每轮张数 / 间隔。改了立即生效；只存与 `.env` 不同的项，标出 `.env` 的值并能一键改回；不合法的整笔拒绝并说明哪项。
- **Translations**：逐条显示英文与译文，默认只看缺的，可搜索；描述丢了标记拒收；Export corpus。
- **Accounts**：账号、列表 / 条目 / 评分数、会话与最近登录；设 / 撤管理员、强制登出、删除（不能作用于自己）。
